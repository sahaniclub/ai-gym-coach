# AI Gym Coach

An AI-powered fitness coaching application built with Python, Streamlit, MediaPipe, and OpenCV.

### Features
- Pose detection using computer vision
- Interactive fitness assistance
- AI-based coaching integration

### Tech Stack
Python • Streamlit • MediaPipe • OpenCV • Groq API

### Installation

```bash
git clone https://github.com/shradha-khapra/ai-gym-coach.git
cd ai-gym-coach/"Main App"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Run

```bash
streamlit run main.py
```

### Requirements
Python version compatible with the project dependencies. Webcam and API key may be required for certain features.
